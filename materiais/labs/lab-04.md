# Revisão - Fechamento do Caixa

Uma loja realizou `n` vendas ao longo do dia. Para cada venda, são informados o valor da compra e o percentual de desconto aplicado.

Escreva um programa modularizado que processe as vendas e mostre:

1. o valor final de cada venda;
2. o total arrecadado no dia;
3. o total de descontos concedidos.

Use funções para calcular o desconto e o valor final.

Entrada:

1. um inteiro `n`, representando a quantidade de vendas;
2. para cada venda, dois números reais: valor da compra e percentual de desconto.

Saída:

1. para cada venda, uma linha no formato `Venda: X.XX`;
2. ao final, uma linha no formato `Total arrecadado: X.XX`;
3. ao final, uma linha no formato `Total descontos: X.XX`.

Mostre todos os valores monetários com duas casas decimais. Sugestão: use `#include <iomanip>`, `fixed` e `setprecision(2)`.
